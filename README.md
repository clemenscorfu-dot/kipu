# kipu

**save now. find later.**

Kipu is a mobile-first app for capturing things you want to remember later — by voice, text, camera or file — and finding them again through search, context and location.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- lucide-react

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

The repository currently contains the initial frontend foundation and a first mobile capture home screen. No Supabase, authentication, AI or external APIs are connected yet.
